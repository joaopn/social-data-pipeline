{#- The settings box of the top bar: a gear button that opens a small floating box (a dialog placed by app.css, no inline style). What it holds is kept per browser (localStorage, through app.js and theme.js), never sent to the server: the theme (`sdp.theme`: dark, light or follow the browser) and the default model for new chats (`sdp.defaultModel`: "opus", "sonnet", "haiku", or empty for the backend's default; the new-chat form reads it). Without the browser's storage the box still changes the open page, and the page is dark. Under them, apart, "This deployment": the read-only query limit for chats, one value of the server for the whole deployment, asked from `GET /settings/deployment` the first time the box opens (`_settings_deployment.html`) and changed through the pending page with the management password; the two browser settings work without it. -#}
